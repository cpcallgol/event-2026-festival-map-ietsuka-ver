紅華祭 電子案内マップ　plan2 体験案内・看板番号 ver12 対応
===============================================

このフォルダーは【2案目】です。
閲覧画面：PowerPoint 6・7枚目に合わせ、上部に模擬店のキャッチコピーを順番に表示し、選択後はそのカテゴリーの企画画像を表示します。
今回送付いただいた地図・画像・企画情報・フロア配置と、手動で割り当てたピン番号を引き継いでいます。

【起動する】
1. ZIPを右クリックし「すべて展開」で展開してください。
2. 展開先のフォルダーを開きます。
3. 作成・編集：start_editor.bat をダブルクリックします。
   閲覧：start_all.bat をダブルクリックします。
   フロア配置の編集は、作成画面上部の「フロア図編集」から開きます。
4. 作成・フロア図編集画面は Ctrl+Alt+I で終了できます。未保存の場合は「保存して終了」を選びます。
   閲覧サーバーは、起動時の黒い画面で Ctrl+C を押して終了してください。
   閲覧画面が全画面の場合は Alt+F4 で閉じられます。

ZIPの中から直接起動しないでください。
Python 3.10以降が必要です。これまでと同じFlask・Waitress・Pillowを使用し、新しいパッケージは追加していません。
必要なパッケージが既に入っていれば、インストールは不要です。初回のみ setup.bat または起動時の自動設定で導入します。
自分のPCだけで使う設定です。

この案のURL
・閲覧： http://127.0.0.1:5010/
・作成： http://127.0.0.1:5011/

【標準ピンと企画の登録】
・「標準ピン」でカテゴリーを選び「OK」を押します。
・ピンをドラッグして移動します。ダブルクリック・ダブルタップで企画を編集します。
・「アイコン追加」で画像を選び、企画名・学科または団体・場所・説明文を入力して「決定」を押します。
・学年は「指定なし（合同など）」・1年・2年から選べます。学科を選んだまま学年を指定しない登録もできます。
・施設案内以外のすべてのカテゴリーで「体験の案内を入力・表示する」を選べます。
  チェックした場合だけ、所要時間・開催時間・対象者・定員を入力でき、閲覧画面にも表示されます。
  例：15分／10:00〜15:00／小学生以上／各回10名・先着順。各欄は任意です。
  チェックを外してそのまま進むと、閲覧画面には体験案内を表示しません。
  入力済みの内容はチェックを外しても保持し、再びチェックすると入力欄に戻ります。
  これまで体験案内を入力済みの企画は、初回読み込み時にチェックが入ります。
・模擬店にはキャッチコピーの欄があります。2案目の上部に順番に表示します。
  未入力の場合は既存の説明文を使います。説明文もない場合は案内文を表示します。
・最後に「すべて保存」を押してください。別の閲覧画面には通常15秒以内に反映されます。

【画像の背景を透過する】
・PCから新しい画像を選ぶと「追加する画像を確認」が開きます。
・「背景を透過する」を選ぶと、透過後のプレビューを確認できます。
・切り抜きの値は常に100％固定です。画像ごとの調整は不要です。格子模様の部分が透明です。
・必要な部分が消えていないことを確認し、「この画像を追加」を押します。
・選択しない場合は、元の背景のまま追加します。
・校内マップの画像・企画アイコン・フロア図に追加する画像のすべてで選択できます。
・四隅につながった単色の背景を対象にします。写真のような複雑な背景には対応していません。
・元画像は data/image_originals に保持します。

【施設アイコンと吹き出し】
・「施設アイコン」からトイレ・受付などを選択し、施設名と場所を登録できます。
・マップ上の画像を選び、上部の「吹き出し」を選ぶと白い背景と縁・しっぽを付けられます。
・元のウォーターサーバーは見つけやすいよう吹き出しを初期表示します。個別に解除できます。
・サイズ・位置固定・90°回転も上部で変更できます。

【画像を自由に置く】
・「画像を置く」から矢印などを選びます。企画情報の登録は不要です。
・PCから画像を追加することもできます。
・ドラッグ、サイズ変更、90°回転、位置固定を使えます。
・画像を選択し、Deleteキーで削除の確認画面を開けます。ごみ箱も使用できます。
  文字やサイズの入力中は、Deleteキーで配置が消えることはありません。
・「余白を除く」は初期状態で有効です。透明・単色の外側の余白を表示時だけ取り除きます。
  四隅の色が異なる写真などは、不要に切り取らず元の画像を表示します。
  全体を表示したい場合は「余白を除く」を外してください。元画像は変更しません。
・画像のサイズは、縦横比を保った長い辺の大きさです。24〜1200の範囲で調整できます。
  上部の数値や＋・−、選択中の画像の右下の青い印のドラッグで変更できます。
  青い印にキーボードの焦点があるときは、矢印キーで10ずつ変更できます。
・施設の吹き出しは、画像のまわりに付けます。余白の大きさではなく画像本体を拡大します。
・校内マップ上の施設画像やピンを削除すると、そこに登録した企画も削除されます。
  確認画面の件数と内容を確認してください。装飾画像は配置だけを削除します。
・フロア図のDeleteキーは配置だけを削除し、企画情報・元画像を保持します。

【カテゴリーを追加・変更・削除する】
・上部の「カテゴリー管理」を押します。
・名前・色・企画画像の表示場所を選んで追加します。最大20件です。
・既存カテゴリーの「変更」で名前・色・説明を変更できます。
・企画・ピンが登録されたカテゴリーを削除する場合は、移動先を選んでください。
  登録した企画・ピンと、割り当て済みの共通番号を保持します。
・施設案内の移動先は施設案内のカテゴリーを選びます。移動先がない場合は先に追加します。
・変更後は管理画面を閉じ、「すべて保存」を押してください。

【フロア図の配置・拡大】
・「フロア図編集」で階を選びます。左側の企画の「配置」を押すとアイコンを置けます。
・フロア図上のアイコン上部の名前は表示しません。企画名は左の一覧と画像の説明で確認できます。
・白い余白を抑えて図面の部分を大きく表示します。元画像と配置座標は変更しません。
・フロア図の「＋」「−」で拡大・縮小します。「全体」で見やすい表示に戻します。最大600%です。
・余白をドラッグすると表示範囲を動かせます。アイコンをドラッグすると配置を変更できます。
・拡大・表示の移動だけでは配置データは変わりません。
・配置変更後は「すべて保存」を押します。
・閲覧画面でもフロア図を拡大・縮小できます。「大きく開く」で大きな枠を開けます。

【閲覧画面】
・カテゴリー・企画画像・マップのピンを選ぶと、詳しい案内が右側に表示されます。
・選択したピンを枠・拡大・短い星の演出で強調します。
・動きのあり／なしボタンは削除しました。端末側の「動きを減らす」設定は引き続き優先します。
・「戻る」で前の案内へ、「最初に戻る」で最初の画面へ戻ります。
・2案目のキャッチコピーは通常7秒ごとに切り替わります。左右のボタンでも切り替えられます。
  マウスを重ねている、またはキーボードで選択している間は自動切替を止めます。

【データの保管】
・編集内容：data/guide.json
・保存前のバックアップ：data/backups
・地図・画像：static/images
・フォルダー全体をコピーすると、編集内容と画像をまとめて保管できます。
・元のデータが必要な場合は、変更前のフォルダーも残してください。

【インターネット公開（GitHub Pages）】
閲覧画面を、学校外のスマートフォンやPCからも見られるように公開しています。
公開URL: https://cpcallgol.github.io/event-2026-festival-map-ietsuka-ver/

【起動しないとき】
黒い画面にエラーが出た場合は、その内容を確認してください。
start_editor.bat・start_main.bat は起動エラーで画面をすぐ閉じない設定を維持しています。
ブラウザーだけで開く場合は、上記のURLを入力します。サーバーの黒い画面は開いたままにしてください。

【Ctrl+Alt+I で作成プログラムを終了する】
・校内マップ・フロア図の編集画面で使えます。確認画面で「終了する」または「保存して終了」を押します。
・保存に失敗したときは終了せず、編集画面に戻れます。
・企画の詳細入力中やピン番号の割り当て中は、先に「決定」・「完了」または「取り消し」を押してください。
・作成サーバーを終了します。PCの電源と、別に起動している閲覧サーバーはそのままです。
・終了後はタブを閉じてください。再開は start_editor.bat です。

【既存の編集データを引き継ぐ】
・現在のプログラムを終了してから更新してください。
・軽量更新用ZIPは、展開した中身を既存のプログラムフォルダーに上書きします。
  dataフォルダー・static/imagesフォルダー・viewer_config.py は更新用ZIPに含まれません。
  作成した企画・配置・追加画像・案ごとの起動ポートを保持できます。
・完全版ZIPを別のフォルダーに展開して移行する場合は、現在の data と static/images を
  それぞれ同じ場所に上書きコピーしてください。

【カテゴリーに関係なくピン番号を付ける】
・番号付きピン全体で、1、2、3…の共通番号を使います。カテゴリーの色や企画の分類はそのままです。
・以前のカテゴリー別番号は、初めて読み込むときにピンの登録順で共通の通し番号にそろえます。
  位置・ピンID・企画情報・画像・フロア配置は引き継ぎます。
・新しく配置するピンには、カテゴリーに関係なく、まだ使われていない最小の番号を付けます。
・ピンを削除しても、ほかのピンの番号は変えません。
・「番号振り直し」で、すべての番号付きピンを1から振り直せます。
  「登録順に自動で付ける」：現在の登録順で、全カテゴリーを通して番号を付けます。
  「好きな順にピンを押して付ける」：1番にしたいピンから順に押します。カテゴリーをまたいで選べます。
・手動ではすべてのピンを押してから「完了」を押します。途中の「取り消し」で元の番号に戻せます。
  キーボードでもピンに焦点を合わせ、Enterまたはスペースで割り当てられます。
・最後に「すべて保存」を押してください。保存した順番は、再起動・カテゴリーの変更や削除後も保持します。
・画像・施設アイコンのように、もともと番号がない配置には番号を追加しません。

【plan2：フロアマップの重なり順を修正】
・校内マップに追加した画像が、フロア図の表示枠を覆わないようにしました。
・画像の追加順、ピンの選択、強調表示やドラッグにかかわらず、フロア図を手前に表示します。
・フロア図内の企画アイコン、拡大・縮小、表示の移動、「大きく開く」は引き続き使えます。
・校内マップ編集のフロア案内枠も、画像に隠れず操作できます。
・ピン番号・配置座標・企画情報・元画像は変更しません。
・更新後は作成・閲覧プログラムを再起動し、開いているブラウザーも再読み込みしてください。

【看板に案内先の番号を重ねる】
・「まずは　の本部テントへ！」の看板の空欄には、今回のデータで1番のピンを初期表示します。
  校内マップ上の案内先ピンの位置・企画情報は変更しません。
・閲覧画面の看板番号は、タッチしても企画を開かない案内用の表示です。
・案内先のピン番号やカテゴリーの色を変えると、看板の番号・色も連動します。
・変更するときは、校内マップ編集で看板画像を選び、上部の「看板の番号」を押します。
  案内先のピンを選び、プレビューの番号をドラッグして位置を調整します。
  横位置・縦位置・大きさの数値でも調整でき、「位置と大きさを戻す」で初期位置に戻せます。
・「画像に案内番号を表示する」を外して「決定」すると、その画像の番号を非表示にできます。
・「取り消し」では設定を変更しません。「決定」の後は「すべて保存」を押してください。
・看板画像を動かす・拡大する・回転する場合、重ねた番号も一緒に動きます。
・案内先のピンを削除した場合は、看板の番号も解除します。
